# Content Management Guide

Managing sources (Phase 1): open **Admin > Content sources**. Add a source with its HTTPS base URL, category, language, priority and retention policy; read its terms and robots.txt; then enable it. Use **Queue scan** to record a manual scan request (processing arrives in Phase 4), **Scan history** to review runs, **Archive** to retire a source (it keeps history) and **Delete** only for archived sources.

The review workflow for collected content (Discovered -> Pending Review -> Verified -> Published) is part of Phase 6.
